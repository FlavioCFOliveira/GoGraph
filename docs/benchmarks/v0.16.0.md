# Benchmark Record — GoGraph v0.16.0

This is the per-release benchmark record that `internal/docscheck`
(`TestPerReleaseBenchmarkReportExists`, rmp #1398) requires for every release.

## Scope

**No release-time benchmark campaign was run for `v0.16.0`.** Benchmark execution is not part
of the release path (see [docs/release.md](../release.md)). Every figure below is a
development-time measurement recorded in the body of the commit that shipped the change, against
that commit's own control, on the development host. The rows measure different workloads, are
**not additive**, and **no whole-release delta is claimed**.

**No load test at the published 1, 8, 64, 256 and 1 024 goroutine concurrency levels was run for
this release.**

## Costs recorded

- `e7d59dc3`: the all-equal-start-instant case of `Server.Transactions`, reachable only with a
  frozen clock, is up to 5.7 % slower.
- Writes to the same object now serialise across the fsync of a durable commit (rmp #2965); no
  release-level throughput figure for this cost was measured.

## Not measured for this release

- The WAL v2 write path (segment rollover, 36-byte frame header, id reservations) against the
  `v0.15.0` single-file WAL.
- Recovery time of a migrated store against a legacy one.
- The concurrency ladder (1, 8, 64, 256, 1 024 goroutines).
