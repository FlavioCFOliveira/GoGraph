# Isolating benchmarks for the count-store-gated reordering peepholes (sprint 307
# #2094): the single-edge anchor swap (#2090) and the disjoint-component ordering
# (#2091). Both toggle a single EngineOptions flag on the SAME binary so the delta
# is attributable to the peephole alone.
#
#  * AnchorSwapHub: MATCH (a:Hub)<-[:R]-(b:Leaf) over a hub with a large R
#    in-degree (20000 in-edges) and 50 leaves, one with a single R out-edge.
#    _Swapped  = peephole ON  (NewEngine default) — re-rooted onto :Leaf, DirOut.
#    _Written  = peephole OFF (EngineOptions{DisableAnchorSwap:true}) — hub-anchored
#                DirIn expand walking the whole R in-degree.
#  * JoinReorderDisjoint: MATCH (a:Big),(b:Small) RETURN count(*) with Big=60000,
#    Small=3. _Reordered = peephole ON — small side drives (|Small| inner re-inits).
#    _Written  = peephole OFF (EngineOptions{DisableJoinReorder:true}) — large side
#                drives (|Big| inner re-inits).
#
# The result multiset is identical ON vs OFF (proven byte-identical by the
# differential tests cypher/anchor_swap_diff_test.go and cypher/join_reorder_diff_test.go,
