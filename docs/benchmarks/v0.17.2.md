# Benchmark Record — GoGraph v0.17.2

This is the per-release benchmark record that `internal/docscheck`
(`TestPerReleaseBenchmarkReportExists`, rmp #1398) requires for every release.

## Scope

**No release-time benchmark campaign was run for `v0.17.2`.** Benchmark execution is not part
of the release path (see [docs/release.md](../release.md)). Every figure below is a
development-time measurement of sprint 369 (rmp #3122 to #3125), recorded in the `## [0.17.2]`
entry of [CHANGELOG.md](../../CHANGELOG.md) and in the commit messages cited, and measured on
the code this release ships. The rows measure different workloads, are **not additive**, and
**no whole-release delta is claimed**.

**No load test at the published 1, 8, 64, 256 and 1 024 goroutine concurrency levels was run for
this release.**

## Recorded measurements

The workload is the one that reproduced the defect: 600 committed nodes, then
`MATCH (a), (b), (c) CREATE ()` cut by a context deadline.

| Change | Measurement | Source |
|---|---|---|
| Abort withdraws statement-created nodes; batched tombstone flips (rmp #3122, #3123) | 1 s deadline: return 8.6–9.2 s → about 1.4 s after the deadline; peak heap about 1.7 GB → about 0.75 GB | CHANGELOG `## [0.17.2]`; commits `b1e9e21f`, `2885d7d3` |
| Same (rmp #3122, #3123, #3125) | 5 s deadline: return 64 s → about 7.1 s after the deadline; peak heap 7.2 GB → about 3 GB | CHANGELOG `## [0.17.2]`; commit `2885d7d3` |
| Pre-sized withdrawal lists; one bitmap `Or`/`AndNot` per batch of at least 1 024 ids (rmp #3125) | 5 s cut `CREATE` rollback: allocation 307 B → 197 B per id, relative to `b1e9e21f` | CHANGELOG `## [0.17.2]`; commit `2885d7d3` |
| `DELETE` rollback (rmp #3124) | measured linear; no change made | CHANGELOG `## [0.17.2]`; commit `2885d7d3` |

## Costs recorded

- Rollback remains linear: about 1 µs per created node (CHANGELOG `## [0.17.2]`).

## Not measured for this release

- `v0.17.2` against `v0.17.1` on any whole-module workload.
- The concurrency ladder (1, 8, 64, 256, 1 024 goroutines).
- The `v0.17.1` cost of releasing minted keys on abort (about 1.5 s per about 1.6 M released
  ids), which was not re-measured.
