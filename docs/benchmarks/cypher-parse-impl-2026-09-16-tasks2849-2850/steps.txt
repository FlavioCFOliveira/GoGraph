Method is the #2846 spike's, unchanged: ONE PROCESS PER ARM, because the
generated parser's decisionToDFA is process-wide, interleaved arm-by-arm across
10 repetitions. Build: no -race, no tags — the same build the spike's ceilings
were measured under, because allocs/op is not build-invariant.

Each task's "Before" arm is a VERBATIM copy of the pre-change code carried in
the harness (stripLiteralsBefore, parseStatementBefore), and its "After" arm
calls the shipped function, so the two arms differ in exactly the change under
measurement. TestMeasureStripEquivalence gates the strip pair over the corpus.
